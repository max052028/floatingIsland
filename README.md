# 浮空島 Floating Island

用 three.js 打造的沉澱、療癒系模擬經營 + 建造遊戲。

在一座漂浮於雲海之上的小島上栽種、製作物品，完成來自地面居民的訂單。
島上有日夜更替、多變的天氣，偶爾還會出現極光、鑽石塵這類特別的奇景。
視角可以在 **45° 俯視**（方便操作）和 **第三人稱**（沉浸式賞景）之間隨時切換。

## 快速開始

```bash
npm install
npm run dev      # 開發伺服器，預設 http://localhost:5173
npm run build    # 輸出到 dist/
npm test         # 核心邏輯的單元測試
```

需要 Node 20.19+（或 22.12+）。進度會自動存在瀏覽器的 localStorage。

## 目前有的東西（第一版原型）

**經營與建造**
- 5 種作物（小麥、胡蘿蔔、番茄、薰衣草、草莓），有的收成後會再長
- 5 種建築／裝飾：工作台、燈籠、花圃、小樹、石板路
- 在工作台把作物做成麵包、蔬菜湯、果醬、花草茶、花束
- 地面居民會不定時下訂單；湊齊物品後用繩籃從島邊送下去，換金幣

**世界**
- 程序生成的低多邊形浮空島，島下方是無盡的雲海
- 日夜循環（一天約 6 分鐘），太陽、月亮、星空、燈籠夜間會亮起
- 8 種天氣：晴、多雲、起霧、細雨、下雨、雷雨、下雪、花瓣飄落；下雨時土壤會變深、作物長得更快，下雪則較慢
- 特別奇景：**極光**（夜晚）、**流星雨**（夜晚）、**鑽石塵**（清晨）。奇景出現時會自動放晴

**鏡頭**
- **45° 視角**：固定 45° 俯角，WASD 平移、Q/E 或右鍵拖曳旋轉、滾輪縮放，滑鼠點哪裡就對哪個格子動作
- **第三人稱**：控制角色在島上走動，右鍵拖曳環顧（往上拖可以仰望天空），對面前的格子動作
- 按 `C` 平滑切換。45° 視角看不到天空，所以奇景最適合在第三人稱下欣賞；極光出現時 45° 視角的雲海和島上光線也會染上顏色

## 操作

| 按鍵 | 功能 |
| --- | --- |
| `C` | 切換 45° / 第三人稱 |
| `WASD` / 方向鍵 | 45° 視角平移，第三人稱走路（`Shift` 加速） |
| `Q` `E` / 右鍵拖曳 | 旋轉鏡頭 |
| 滾輪 | 縮放 |
| 左鍵 / `Space`（第三人稱） | 對目標格子執行動作 |
| `1` `2` `3` | 耕作 / 建造 / 移除 |
| `4` | 打開工作台製作 |
| `Tab` | 切換目前的種子或建築 |
| `F2` 或 `` ` `` | 除錯面板（調整時間、天氣、觸發奇景） |

## 專案結構

```
src/
  game/      純邏輯，不依賴 DOM 或 three.js（有單元測試）
    data.js      作物、配方、建築、居民等資料表
    state.js     遊戲狀態：種植、收成、建造、製作、訂單、時間、存檔格式
    actions.js   「工具 + 目標格」→ 預覽文字與可執行動作
    weather.js   天氣狀態機與參數混合
    save.js      localStorage 存取
  world/     three.js 場景
    island.js    程序生成的浮空島與周邊裝飾
    sky.js       天空穹頂、日月星辰、全部光源與霧
    clouds.js    雲與雲海
    precip.js    雨、雪、花瓣
    events.js    極光、鑽石塵、流星雨與觸發排程
    farm.js      格子上的作物與建築模型
    player.js    角色    cursor.js 目標格高亮    delivery.js 運送繩籃
  camera/    rig.js（兩種視角與平滑切換）、input.js（鍵鼠輸入）
  ui/        hud.js（訂單、工具列、製作視窗）、debug.js（除錯面板）
  main.js    把一切接起來的主迴圈
tests/       node:test 單元測試
```

遊戲邏輯和畫面刻意分開：所有玩家行為都經過 `GameState`，畫面只監聽它發出的事件，
所以之後換掉渲染或加新玩法都不太會牽動核心規則。
